# Scientific Calculator 🧮

A **fully functional scientific calculator** built with Python — supports basic arithmetic and advanced scientific functions right from the terminal.

![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)

---

## ✨ Features

- ➕➖✖️➗ **Basic arithmetic** — add, subtract, multiply, divide
- √ **Square root**
- ^ **Power / exponent**
- 📐 **Trigonometry** — sin, cos, tan (in degrees)
- 📊 **Logarithm** — natural log
- 🔄 **Continuous calculation** — keep going without restarting
- ❌ **Error handling** — division by zero, invalid input

---

## 🚀 How to Run

```bash
git clone https://github.com/Eshwarkadari/sci_calculator.git
cd sci_calculator
python sci_calculator.py
```

---

## 💻 Usage Example

```
=== Scientific Calculator ===
Operations: +, -, *, /, sqrt, pow, sin, cos, tan, log

Enter operation: sin
Enter angle in degrees: 90
Result: 1.0

Enter operation: sqrt
Enter number: 144
Result: 12.0

Enter operation: pow
Enter base: 2
Enter exponent: 10
Result: 1024.0
```

---

## 📋 Supported Operations

| Operation | Input | Example |
|-----------|-------|---------|
| Addition | `+` | 5 + 3 = 8 |
| Subtraction | `-` | 10 - 4 = 6 |
| Multiplication | `*` | 6 * 7 = 42 |
| Division | `/` | 15 / 3 = 5 |
| Square Root | `sqrt` | √144 = 12 |
| Power | `pow` | 2^10 = 1024 |
| Sine | `sin` | sin(90°) = 1 |
| Cosine | `cos` | cos(0°) = 1 |
| Tangent | `tan` | tan(45°) = 1 |
| Logarithm | `log` | log(e) = 1 |
